## Auraplex Material Stock Checker v1.0.0

Initial portable Windows release.

### Features
- BOM material requirement calculation
- Storage stock comparison
- Product ID search
- Production quantity input
- Shortage / Exception / Enough classification
- Excel report export
- Google Drive for Desktop compatible

### Result colours
- Red: SHORTAGE
- Yellow: EXCEPTION
- White: ENOUGH

### Installation
No installation required.

Download the Portable ZIP, extract it and run:

Auraplex_Material_Stock_Checker.exe

### Requirements
Windows 10/11.

Google Drive for Desktop is required only when accessing
company files through Google Drive.

### Important
The tool does not modify the selected Storage or BOM workbook.

The application is not digitally signed. Windows may show an
"unknown publisher" notice on first start.
